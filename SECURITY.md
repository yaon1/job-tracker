# Безопасность

Об уязвимостях сообщайте через [приватный advisory](https://github.com/yaon1/job-tracker/security/advisories/new).

- В базе личные данные (контакты рекрутеров, зарплаты): не открывайте API в интернет без `API_TOKEN` и HTTPS.
- Токен в ссылке календаря видят все, у кого есть ссылка; при утечке смените `API_TOKEN`.
- Веб хранит токен в `localStorage` браузера; на чужом компьютере после работы выйдите (очистите данные сайта).
