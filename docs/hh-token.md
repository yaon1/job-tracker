# Токен hh.ru для импорта вакансий

С конца 2025 года api.hh.ru не отвечает на анонимные запросы (403), поэтому импорту нужен токен приложения.

1. Зарегистрируйте приложение на [dev.hh.ru](https://dev.hh.ru/admin) (тип — «для себя»).
2. После одобрения получите токен приложения (client credentials):

   ```bash
   curl -X POST https://api.hh.ru/token \
     -d grant_type=client_credentials -d client_id=$CLIENT_ID -d client_secret=$CLIENT_SECRET
   ```

3. Передайте `access_token` в переменной `HH_ACCESS_TOKEN` контейнеру `api`.

Токен приложения не даёт доступа к вашему аккаунту и откликам — только к публичным вакансиям. Без токена всё остальное работает, вакансии добавляются вручную.
