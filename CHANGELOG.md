# Changelog

## [0.2.0] — 2026-10-20

### Добавлено
- Контакты, журнал, теги и версия резюме у каждого отклика.
- Собеседования и iCal-лента с напоминанием за 30 минут.
- Напоминания о наступивших следующих шагах.
- Фильтры (тег, источник, зарплата), сортировка и пагинация.
- Статистика по источникам и медиана времени до ответа.
- CSV-экспорт и импорт (всё или ничего), предупреждение о дубликатах.
- Импорт с hh.ru: опыт, график и город в заметках; поддержка токена приложения.
- Защита API токеном, `/health`, OpenAPI-спецификация, демо-данные, smoke-тест.
- Интерфейс: форма токена, повестка, CSV-кнопки, горячие клавиши, пустое состояние, мобильная доска.

### Исправлено
- Целые параметры SQL привязываются как числа (фильтр по зарплате ничего не находил).
- Вложенные транзакции при импорте.
- Healthcheck при включённом токене.
- Lock-файл веба, из-за которого `npm ci` падал в Docker.

## [0.1.0]

- Канбан откликов, импорт с hh.ru, история статусов, воронка, Docker Compose.
